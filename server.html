로엔 야생이란?

서버의 기본적인 방향과 플레이 환경

로엔 야생은 Minecraft를 기반으로 한 야생 서버입니다. 플레이어가 자유롭게 월드를 탐험하고, 건축과 생활을 즐기며 다른 플레이어와 함께 서버를 만들어가는 것을 목표로 합니다.

기본적인 야생 플레이를 중심으로 다양한 콘텐츠와 시스템을 제공하며, 처음 방문한 플레이어도 쉽게 적응할 수 있는 환경을 지향합니다.

서버 특징

로엔 야생에서 제공하는 주요 플레이 방향입니다.

01

자유로운 야생

원하는 장소를 찾아 정착하고, 자신만의 방식으로 야생 생활을 즐길 수 있습니다.

02

생활 중심 플레이

채집, 건축, 탐험 등 Minecraft의 기본적인 재미를 편안하게 즐길 수 있는 환경을 제공합니다.

03

다양한 콘텐츠

야생 외에도 서버의 여러 시스템과 콘텐츠를 통해 장기적으로 즐길 수 있는 플레이를 지원합니다.

04

커뮤니티

다른 플레이어와 함께 활동하고 소통하며 서버 안에서 자신만의 이야기를 만들어갈 수 있습니다.

접속 안내

Minecraft Java Edition에서 로엔 야생에 접속하는 방법

에디션 Java Edition
권장 버전 1.21.4
서버 주소 roen.kro.kr
01

마인크래프트 실행

Minecraft Launcher를 실행한 뒤 Java Edition을 선택합니다.

02

버전 선택

버전 목록에서 1.21.4를 선택하고 게임을 실행합니다.

03

멀티플레이어 선택

Minecraft 메인 화면에 들어오면 멀티플레이어를 선택합니다.

04

서버 추가

멀티플레이어 화면에서 서버 추가를 클릭합니다.

05

서버 정보 입력

서버 이름에는 원하는 이름을 입력하고, 서버 주소에는 아래 주소를 입력합니다.

roen.kro.kr
06

서버 저장

입력이 완료되었다면 완료 버튼을 눌러 서버를 저장합니다.

07

서버 접속

멀티플레이어 서버 목록에서 로엔 야생을 선택한 뒤 서버 참여를 클릭합니다.

08

접속 완료

서버 접속이 완료되면 로엔 야생에서 자유롭게 플레이를 시작할 수 있습니다.
